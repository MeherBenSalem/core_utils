# Core Utilities 2.0.4

## Added

- **Minecraft 26.3 is now supported, on Fabric and NeoForge.** Download the file with `26.3` and your loader in its
  name. Fabric still needs Fabric API. Everything from 2.0.3 is there: power, machines, cables, item pipes, the quarry,
  automation, the manual and the original utilities.

No gameplay, config or save changes on the other versions.
